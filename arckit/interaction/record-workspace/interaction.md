# 业务记录工作区 - 交互规范

## 交互策略

### 核心任务

用户在同一上下文中理解一条业务记录的当前状态、允许动作、关联事实和历史，并安全完成一次状态变化。

### 用户场景

- 操作者打开记录，需要先看懂当前状态和下一可执行动作。
- 操作者发起状态变化，需要在提交前理解影响并完成必要输入。
- 操作者提交成功，需要核对稳定 ID、revision、变化摘要和下一步。
- 操作者遇到并发冲突、非法状态或外部引用不可用，需要保留输入并恢复。
- 评估者需要查看历史，确认事实没有被静默覆盖。

### 主路径

用户进入记录 → 阅读摘要和当前状态 → 选择服务端允许的动作 → 补充必要输入并确认影响 → 提交 → 查看结果、revision 和下一动作 → 在历史中核对变化。

### 决策点

- 主操作由当前状态和 `allowed_actions` 决定，页面不根据客户角色名自行推断。
- 不可逆或影响余额、合同效力、文件可用性、项目终态的操作要求确认。
- 外部引用失败时，用户可以查看当前应用事实，但依赖该引用的动作失败关闭。
- 并发冲突时，用户选择加载最新状态或放弃当前输入，系统不自动覆盖。

### 信息揭示

业务名称、状态、核心数值、负责人和主操作首先出现。关联事实、详细字段和历史作为同页分区。技术 ID、revision、幂等结果和来源摘要保持可复制，但不压过业务语言。

### 状态流

- 已就绪：显示摘要、允许动作、关联事实和历史。
- 编辑与确认：操作面板显示必要输入、影响说明和确认动作。
- 提交成功：原位显示结果、稳定 ID、revision、变化摘要和下一步。
- 冲突／失败恢复：保留用户输入，显示失败类型、影响范围和恢复选择。
- 权限变化恢复：收到 401／403 或用户显式刷新权限后，立即退出编辑态，以新 `allowed_actions` 重绘动作；重新签发失败则返回统一工作台。

### 反馈与恢复

提交期间禁用重复提交并显示进行状态。成功反馈不只显示“成功”，还显示业务结果。字段错误就地显示。并发冲突保留草稿并提供对比；外部不可用标明来源；网络错误允许使用同一幂等意图安全重试。

### 输入输出边界

页面只提交当前应用拥有的命令字段。关联应用事实通过稳定 ID 和版本化摘要读取；页面不能跨应用直接编辑。输出包含当前记录、revision、允许动作、关联摘要和追加历史。

### 线框投影要求

`default.html` 显示“已就绪”“编辑与确认”“提交成功”“冲突恢复”“权限变化恢复”五个独立状态。每个状态均保留记录身份、当前状态和历史入口。

## 页面状态

| 状态 | 触发条件 | 关键控件 |
| --- | --- | --- |
| 已就绪 | 记录读取成功 | 摘要、状态、动作区、关联事实、历史 |
| 编辑与确认 | 用户选择一个允许动作 | 影响说明、必要字段、确认与取消 |
| 提交成功 | 命令完成或幂等复用 | 结果摘要、稳定 ID、revision、下一步 |
| 冲突恢复 | revision 过期、非法状态或外部依赖失败 | 草稿保留、错误说明、重新加载、重试 |
| 权限变化恢复 | 显式刷新后 Capability 改变，或命令返回 401／403 | 只读摘要、刷新权限、返回工作台 |

## 导航流程

### 进入方式

用户从业务记录列表、Demo 首页的最近变化或组合页面中的稳定引用进入。

### 页面内导航

页面内使用摘要、关联事实、历史三个稳定分区。点击关联事实只通过公开读取进入目标页面；目标不可用时留在当前页面。

### 离开方式

返回列表时恢复原筛选。存在未提交输入时离开会显示放弃确认；提交成功后可以直接离开。

## 操作面板

- 页面只突出一个当前推荐动作，其他允许动作按风险和频率排序。
- 危险动作与普通主操作分离，并显示不可逆或纠错方式。
- 不允许的动作如果需要解释则显示为不可用并给出原因；因安全要求不应暴露的动作不显示。
- 表单只询问服务端命令需要的字段，不重复收集可从当前记录或可信上下文获得的信息。
- Project Package 的 attach／wrap 与安全撤销放在独立层级分区；撤销使用高风险确认并要求原因，不把 Package 伪装成普通项目字段。

## 关联事实与历史

- 关联事实显示来源系统、业务名称、稳定 ID、来源 revision 和可用状态。
- 来源不可用时保留上次已确认摘要并标明时间，不把缓存摘要当作当前事实。
- 历史按时间倒序显示动作、操作者、revision 和变化摘要；用户可以展开查看来源快照。

## 弹窗／对话框

| 名称 | 触发 | 内容 |
| --- | --- | --- |
| 高风险操作确认 | 终止、冲销、取消、归档等 | 影响对象、纠错方式、确认动作 |
| 放弃未提交输入 | 用户离开编辑状态 | 保留编辑或放弃 |
| 并发冲突处理 | 服务端拒绝过期 revision | 加载最新状态或保留草稿对比 |

## 错误处理

| 错误类型 | 展示方式 | 恢复操作 |
| --- | --- | --- |
| 字段校验失败 | 字段附近错误和页首摘要 | 修正后再次提交 |
| revision 冲突 | 冲突恢复状态 | 加载最新状态；保留草稿对比 |
| 非法状态 | 动作区错误说明 | 返回当前允许动作 |
| 外部引用不可用 | 关联区和动作区标注来源 | 查看当前事实；稍后重试 |
| 网络或超时 | 原位错误反馈 | 使用同一幂等意图安全重试 |
| 能力被撤销／范围变化 | 页面退出编辑态，旧动作隐藏 | 经 Gateway 向 IAM 刷新；失败则清除旧应用凭证并返回工作台 |

## 加载策略

初次读取保留页面标题并骨架化摘要。提交只锁定当前动作面板，不冻结历史和帮助。重新加载最新 revision 后，页面明确标记哪些输入仍可复用。
