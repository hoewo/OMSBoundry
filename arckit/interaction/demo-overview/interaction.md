# 独立 Demo 首页 - 交互规范

## 交互策略

### 核心任务

用户进入任一小系统后，先理解该系统拥有的业务事实和演示边界，再从一个明确的推荐动作进入代表性业务路径。

### 用户场景

- Demo 操作者刚打开系统，需要在一分钟内知道“这是做什么的”和“第一步点哪里”。首页显示一句问题与结果、演示标识和单一推荐动作。
- 方案评估者需要判断系统是否真的独立。首页显示运行模式、身份提供者、数据范围和未启动依赖，不展示不存在的小系统入口。
- 操作者已经运行过脚本，需要核对当前数据。首页显示关键记录数量、最近业务变化和进入记录的入口。
- 工程诊断者遇到错误，需要查看健康状态、API 和重跑方式。帮助区提供这些入口，但不占据业务主路径。

### 主路径

用户读取产品说明和演示环境 → 确认推荐业务路径 → 触发“开始演示”或“继续演示” → 进入首个业务列表或工作区 → 返回首页核对摘要。

### 决策点

- 当前无数据时，用户选择生成演示数据或进入空白创建路径；首页解释两种选择的差异。
- 当前已有数据时，主操作指向下一未完成步骤；查看全部记录为次操作。
- 服务不可用时，用户先重试；诊断信息按需展开，不要求用户先理解容器或 API。

### 信息揭示

产品名称、用途、演示标识和推荐动作始终首先出现。当前场景、关键数量和最近变化随后出现。能力边界、登录信息、健康检查、API 和脚本说明在帮助区按需展开。

### 状态流

- 加载中：页面框架和产品说明可见，数据摘要显示占位，不禁用帮助入口。
- 已就绪：显示推荐路径、当前摘要、能力导航和最近变化。
- 空状态：显示没有演示数据的原因，并提供一个推荐创建入口和一个生成合成场景入口。
- 错误：保留产品说明，数据区显示失败来源、影响范围、重试和诊断入口。

### 反馈与恢复

开始或继续动作立即进入目标页面。生成演示数据进入进行状态，成功后显示场景名称、稳定 ID 和下一步；失败时保留页面并提供重试。重跑已经存在的命名场景时，系统说明复用已有事实，不暗示重复创建。

### 输入输出边界

首页不接收复杂业务字段，不直接执行不可逆业务终态。它输出当前演示模式、数据摘要、推荐下一步和帮助信息。身份、状态和能力来自服务端结果；前端文案不能替代服务端授权。

### 线框投影要求

`default.html` 显示“已就绪”“加载中”“空状态”“错误恢复”四个独立状态。四个状态都保留产品身份、演示标识和帮助入口。

## 页面状态

| 状态 | 触发条件 | 关键控件 |
| --- | --- | --- |
| 已就绪 | 数据摘要加载成功 | 顶部产品栏、推荐路径、摘要、能力导航、最近变化 |
| 加载中 | 首次进入或刷新 | 页面骨架、摘要占位、帮助入口 |
| 空状态 | 数据库无当前租户演示记录 | 空状态说明、生成演示数据、从空白开始 |
| 错误恢复 | 摘要或依赖读取失败 | 影响范围、重试、诊断详情 |

## 导航流程

### 进入方式

用户直接访问应用根路径，或从完整组合的 Workbench 进入。两种进入方式展示同一系统首页。

### 页面内导航

顶部产品栏提供首页、领域记录和历史／审计。推荐动作进入该系统的首个业务页面。帮助入口展开环境、账号、脚本和 API 信息。

### 离开方式

独立 Demo 不制造跨应用返回入口。组合模式可以返回 Workbench，但应用内部浏览历史仍可正常返回。

## 交互行为

### 推荐路径

- 点击主操作后进入当前路径的下一步。
- 点击步骤标题后进入已完成步骤的详情；未满足前置条件的步骤不可点击并显示原因。

### 摘要与最近变化

- 点击摘要数字后进入已应用相同过滤条件的记录列表。
- 点击最近变化后进入对应记录工作区的历史位置。

### 帮助

- 点击帮助后展开当前 Demo 的访问方式、合成数据说明、账号、重跑、重置、健康检查和 API 入口。
- 敏感凭据不直接显示；页面只显示凭据来源和安全复制入口。

## 错误处理

| 错误类型 | 展示方式 | 恢复操作 |
| --- | --- | --- |
| 当前应用不可用 | 数据区域错误块，产品说明保留 | 重试；打开健康检查 |
| 外部引用不可用 | 受影响摘要标注来源 | 继续使用当前应用；重试引用 |
| 无权限 | 推荐动作不可用并解释所需能力 | 切换演示角色或返回 |
| 场景生成失败 | 原位错误反馈 | 重试；查看演示脚本输出 |

## 加载策略

首次加载只对数据摘要使用占位。页面标题、用途、环境标识、导航和帮助立即呈现。刷新不清空已有内容；失败时保留上一次成功摘要并标记更新时间。
