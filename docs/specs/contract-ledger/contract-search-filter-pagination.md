# Contract Ledger：合同检索、筛选与稳定分页

里程碑：M2  
功能编号：CL-M2-003  
日期：2026-09-19  
状态：已完成并验证

## 目标

用户能够在 Contract Ledger 内快速找到合同，并在数据量增长后仍按稳定、可继续的顺序浏览列表。本功能只读取本系统拥有的合同、最新 revision 和状态，不建设跨系统搜索、报表平台或通用查询引擎。

## 查询条件

合同列表支持组合使用：

- 关键词：不区分大小写地对编号命名空间、合同编号和标题执行字面量包含匹配；
- 状态：精确筛选 `draft`、`active`、`terminated`、`closed` 或 `cancelled`；
- 币种：精确筛选标准化后的三字母币种；
- 游标：继续读取上一页之后的结果。

关键词去除首尾空白，最多 100 个字符。`%`、`_` 和反斜杠只作为普通字符，不允许借查询参数注入 SQL 通配语义。币种为空表示不限，否则转为大写并校验三个英文字母。未知状态、非法币种或无效游标返回可见校验错误，不静默降级为其他查询。

当前功能不搜索主体名称、自由文本审计、Instrument 内容或文件正文；这些需要独立索引与权限设计，不能通过跨表模糊拼接临时实现。

## 返回事实

每一行继续显示：

- 编号命名空间与合同编号；
- 标题和分类；
- 币种与金额；
- 原合同签署／生效日期；
- 当前状态、draft version 或 current revision。

draft/cancelled 合同金额来自草稿；active/terminated/closed 合同金额必须来自当前 revision，不读取 Contract 根表草稿金额作为第二真相源。

## 排序与分页

- 排序固定为 `created_at DESC, id DESC`；
- 每页固定最多 50 条；
- repository 读取 51 条以判断是否存在下一页，页面只返回前 50 条；
- 下一页使用版本化、不透明的 URL-safe 游标，不使用 offset；
- 游标保存上一页末行的 `created_at`、Contract ID 和本次标准化筛选条件；
- 游标只能与生成它的关键词、状态和币种组合使用，格式被破坏或混用筛选条件时拒绝；
- 并发新建的合同位于当前游标之前，不会导致后续页重复；用户刷新第一页后才能看到这些新记录；
- 没有更多记录时不显示下一页入口。

游标不是业务事实，不持久化到数据库，不承担加密防伪，也不作为授权凭据。服务端必须重新校验游标结构、筛选绑定、登录和读权限边界。

## 页面

- `/contracts` 顶部提供关键词、状态、币种筛选表单；
- 查询采用 GET，可复制、刷新和返回；
- 当前筛选值在结果页保留；
- 提供“清除筛选”和仅在有更多结果时出现的“下一页”；
- 空结果与系统中完全没有合同使用不同提示；
- 新建合同表单仍只对 administrator/editor 显示，viewer 可以使用全部只读检索能力；
- 非法筛选返回 `422` 并显示具体错误，不执行 repository 查询。

## 数据库与性能边界

- 查询使用参数化 SQL；
- 状态、币种和创建顺序建立局部适用的 B-tree 索引；
- 关键词采用小系统可接受的字面量 `LIKE` 扫描，不提前引入 PostgreSQL 扩展或外部搜索服务；
- 出现真实规模证据后再决定 trigram、全文索引或独立搜索适配器。

## 明确不做

- 主体、角色、Instrument、审计或附件全文搜索；
- 保存常用筛选、复杂布尔条件、排序选择和自定义字段；
- 跨 Contract Ledger 与 Money Flow Ledger 的统一搜索；
- 搜索服务、通用报表平台或数据仓库；
- 导出、批量修改或批量删除；
- 修改任何合同事实或追加审计。

## 验收标准

1. 关键词分别能按命名空间、合同编号和标题进行不区分大小写的字面量包含检索。
2. `%`、`_`、反斜杠和引号不会改变为通配查询或造成 SQL 注入。
3. 状态、币种以及它们与关键词的组合筛选返回精确结果。
4. active、terminated、closed 行读取最新 revision 金额，draft/cancelled 行读取草稿金额。
5. 空白关键词标准化为空；超长关键词、未知状态、非法币种和非法／混用游标返回 `422` 且不查询 repository。
6. 超过 50 条时第一页固定返回 50 条并产生下一游标，后续页无重复、无遗漏且顺序与 `(created_at, id)` 一致。
7. 获取第一页后并发新增合同不会出现在旧游标后续页，也不会造成重复；刷新第一页可以看到新合同。
8. viewer 可以筛选和翻页但仍看不到新建表单；匿名访问继续受登录保护。
9. 空结果提示、筛选值保留、清除筛选和下一页 URL 行为通过 HTTP 测试。
10. Money Flow 数据库和应用停止时仍能完成全部查询验收，不读取任何跨系统表。
