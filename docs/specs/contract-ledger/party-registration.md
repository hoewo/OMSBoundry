# Contract Ledger：主体登记与列表

里程碑：M1  
功能编号：CL-M1-001  
状态：已接受，首个纵向业务功能

## 目标

用户能够在 Contract Ledger 内登记一个组织或个人主体，并在主体列表中看到已经持久化的结果。该主体目录是本系统的默认本地实现，不依赖外部客户中心或 Money Flow Ledger。

## 业务事实

- Party 表示当前可供选择的业务主体资料；
- `organization` 表示组织，`individual` 表示个人；
- 法定名称或姓名必填，去除首尾空白后长度为 1 至 200 个字符；
- 登记标识可选，去除首尾空白后最长 100 个字符；
- 新建 Party 的 revision 固定从 1 开始；
- Party 当前资料以后发生变化时，不能反向修改已经激活合同中的 Party Snapshot。

## 用户流程

```text
打开主体列表
  → 填写主体类型、法定名称／姓名和可选登记标识
  → 提交
  → 服务端校验
  → 持久化 Party
  → 返回列表并显示创建结果
```

## 验收标准

- 能登记组织主体；
- 能登记个人主体；
- 空名称、非法主体类型、过长名称和过长登记标识被拒绝；
- 输入首尾空白在持久化前被清理；
- 列表能够从 PostgreSQL 读取已登记主体；
- 表单状态变更请求具有 CSRF 校验；
- 数据库写入错误不会伪装成创建成功；
- 单元测试覆盖领域校验和 HTTP 流程；
- 集成测试覆盖 migration、真实 PostgreSQL 写入和读取；
- 功能不依赖 Money Flow、Project、Approval 或外部 Party 服务。

## 本功能不包含

- 编辑、停用和删除主体；
- 主体合并和重复识别；
- 登记标识规则库和真实性核验；
- 批量导入；
- 合同签署时的主体快照；
- 登录身份与业务主体绑定；
- 跨系统同步主体。
