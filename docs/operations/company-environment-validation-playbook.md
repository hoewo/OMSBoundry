# 公司私有 Ubuntu 环境验证手册

日期：2026-09-25  
状态：等待公司授权与目标环境输入；不得在授权前连接、安装或修改公司资源

## 1. 目标

该环境用于证明本地已经通过的同一 BizFoundry 发布物能够迁移到公司拥有的 Ubuntu 服务器，并通过完整入口、业务、故障、升级、备份和恢复验收。它是 OA 完整体架构可行性验证的真实环境候选之一，不替代个人 `xidou.me` 试验田。

## 2. 启动前必须确认

以下内容由公司明确授权并记录：

- 目标服务器用途、负责人、允许的验证时间和回退窗口；
- Ubuntu 版本、CPU 架构、CPU／内存／磁盘、网络区域和可用端口；
- SSH 访问方式、允许来源 IP、账号权限和密钥轮换方式；
- 使用公网域名、公司内网 DNS 还是仅主机名访问；
- HTTPS 使用公网 CA、公司内部 CA 还是其他已批准证书；
- Registry 使用公司 ACR／其他 Registry，还是授权跨账号拉取个人 ACR；
- Evidence 使用公司 OSS、本地文件 Provider 或其他已批准存储；
- 数据库、秘密、日志和备份的保存位置、保留期与可接触人员；
- 是否允许使用非真实演示数据，以及验证结束后的保留或销毁要求。

任何密码、私钥、AccessKey、Registry 密码和数据库秘密都只进入公司批准的秘密载体，不写入仓库、文档、终端历史或聊天。

## 3. 环境所有权边界

- 公司环境拥有自己的域名／DNS、证书、Registry 副本、数据库、OSS／文件、秘密、日志和备份；
- 个人环境的数据库、OSS 对象、证书和秘密不复制到公司环境；
- 可以跨 Registry 复制相同镜像内容，但必须记录源摘要和目标摘要；
- 目标主机不编译业务源码，不修改镜像内文件，不维护现场核心补丁；
- 验证使用非真实数据；真实公司数据另需独立授权、脱敏和处理规则；
- 所有写入、清理和恢复操作只针对已授权的隔离目录、Compose Project、数据库和存储前缀。

## 4. 验证流程

### 4.1 只读盘点

先收集操作系统、架构、磁盘、端口、DNS、证书、Docker／Compose 和存储条件。只读盘点通过后才生成目标配置，不根据个人环境值猜测公司环境。

### 4.2 宿主机基线

使用仓库内幂等引导脚本完成 Docker、Compose、Swap、受限目录和 SSH 基线，并重复执行检查证明没有依赖手工状态。安全组或公司防火墙只开放获批入口；SSH 仅允许批准来源。

### 4.3 制品提升

从已经验证的发布包读取镜像摘要，把相同内容复制到获批 Registry 或使用获批的跨账号拉取方式。目标清单记录每个镜像的名称、平台和摘要；目标服务器只执行 pull-only 部署。

### 4.4 独立配置

为公司环境单独生成：

- Suite Manifest 与 Deployment Profile；
- 域名、证书和入口配置；
- IAM 签名密钥与管理员初始化秘密；
- 每个应用的数据库账号和密码；
- Evidence Provider、OSS／文件路径和访问身份；
- 备份目录、离机目标、日志与保留策略。

环境文件只保存在受限位置，权限检查通过后才能启动。

### 4.5 完整验收

至少验证：

1. 只有 Nginx 对外提供 HTTP／HTTPS，HTTP 跳转 HTTPS；
2. Gateway、IAM、数据库和业务应用内部端口不直接暴露；
3. 一次登录进入 Workbench，并由目标应用执行最终授权；
4. OA 当前业务基线或完整体验证数据能够运行、重放和查询历史；
5. Evidence 上传、完整性校验、受控访问和来源应用引用通过；
6. 逐项停止直接依赖时故障范围符合声明，恢复后继续工作；
7. 关闭／启用应用不删除数据；
8. 升级前备份、空目标恢复、旧 Session 失效和恢复后继续写入通过；
9. 备份复制到目标服务器之外的公司批准位置；
10. 镜像摘要、配置版本、命令、时间和结果进入验收记录。

## 5. 私网访问的 HTTPS 判定

公司服务器不要求必须暴露公网。若只在公司内网使用，可以通过公司内网 DNS 和受信内部 CA 验证 HTTPS；若浏览器或客户端不信任该 CA，不能把证书警告后的手工绕过记为通过。若公司提供已备案公网域名，则按公网入口执行相同验证。

无论公网还是私网，Nginx 仍是唯一边缘入口，Gateway 和应用端口保持内部可达。

## 6. 结果与回退

- 通过：保留目标摘要清单、环境验收报告、离机备份和恢复证据；
- 部分通过：停止结论升级，记录失败层、日志和可重复步骤；
- 失败：执行已批准回退，恢复旧发布物或销毁隔离验证环境；
- 授权撤回：立即停止连接，不扩大访问范围，由公司负责人决定保留或清理。

公司环境通过只证明该授权环境的交付链。个人 `xidou.me` 备案完成后仍作为长期试验田独立验收；两边结果可以比较，但证据和秘密不合并。
