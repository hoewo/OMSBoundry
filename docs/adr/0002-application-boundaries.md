# ADR-0002：一个仓库中的两个独立应用

日期：2026-09-19  
状态：接受，用于当前开发阶段

## 决策

Contract Ledger 和 Money Flow Ledger 位于同一个 Git 仓库，但分别作为独立 Go module 和独立运行应用开发。

允许共享：

- 根目录文档；
- 开发检查命令；
- 将来经过验证的极少量稳定原语。

禁止共享：

- 业务数据库表；
- 领域实体；
- repository 实现；
- 内部 HTTP handler；
- 客户岗位、行业字段和业务状态；
- 运行时必须在线的公共业务服务。

## 数据和运行约束

- 每个应用拥有独立数据库和 migration 历史；
- 根 `go.work` 不是生产运行依赖；
- 每个应用可以被复制到独立目录后测试和构建；
- 未来连接器不得导入应用的 `internal` 包；
- 未来系统联调通过公开 API、事件和快照进行。

## 原因

单仓降低早期文档、版本和本地验证成本；独立 module、数据库和启动入口又能持续证明两个小系统没有隐藏耦合。将来若团队、发布或合规边界要求拆仓，可以沿现有边界移动。
