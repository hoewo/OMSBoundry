# 财务申请发票优先入口本地验证（2026-11-08）

## 结论

BF-320 本地候选把“上传发票并识别”从新建申请的中段选项提升为弹窗最上方、基本信息之前的主入口。新增报销和新增付款申请共用同一结构与识别桥；点击主按钮会先选择“上传并识别”，再进入既有原图识别和人工校对。确认或取消后仍返回当前申请草稿。

本轮只改变 Unified Workbench 的信息层级和响应式样式，没有新增 Owner、API、schema、Capability 或数据库，也没有改变人工确认、Evidence 精确版本、Finance 校验和用户明确保存等边界。

## 实现与不变量

- 新建报销／付款申请都先渲染发票优先录入区，再渲染基本信息。
- 顶部只使用一个绿色主按钮“上传发票并识别”；支持重新上传时文案变为“重新上传识别”。
- 暂不录入、直接录入、上传并识别继续作为互斥方式保留，直接录入仍显示票面字段与原票文件。
- 主按钮点击会显式选中识别方式并调用同一个隐藏文件选择器，避免报销与付款出现两套行为。
- 识别确认继续回填金额、日期、销售方和号码；取消、失败和权限错误继续恢复原草稿。
- 已有申请不显示新建专用入口；既有申请补票／换票仍不在范围。
