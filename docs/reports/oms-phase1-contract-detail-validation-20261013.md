# OMS 一期合同详情验证报告

日期：2026-10-13  
关联：BF-151、[OMS 一期产品设计](../specs/assembly/oms-phase1-mvp-product-design-v1.md)

状态：**合同详情的信息层级、草稿编辑和实际金额异常提醒已实现并发布；未改变任何业务事实 Owner 或数据库。**

## 1. 问题与结果

问题：原项目详情只提供“合同附件”，操作者无法在进入文件前确认这份合同的金额、对象和状态。  
结果：入口改为“合同详情”，右侧抽屉先显示合同类型、名称、状态、精确金额、往来主体、签订／生效日期，再把附件作为下层内容；多份上下游合同时可以切换合同。

草稿合同提供独立“编辑合同”入口，允许修改名称、金额、签订日期和生效日期。保存继续调用 Contract Ledger 原生命令并追加 draft version；Workbench 不保存合同副本。非草稿合同保持只读。

## 2. 金额异常边界

- 唯一上游合同时，拟修改金额若低于该项目已实际回款，输入区立即显示红色提醒，提交前再次确认；
- 唯一“项目＋施工方”下游合同时，拟修改金额若低于已实际支付，同样双重提醒；
- 金额使用十进制字符串和整数最小货币单位比较、格式化，页面固定显示两位小数；
- 同一方向存在多份合同而资金没有指向具体合同时，不把项目聚合回款／支付强行归到某份合同，也不自动报警；
- 本次没有建立发票、应收、回款或付款与合同的一一对应，也没有自动生成相邻事实。

## 4. 不负责范围

本轮不增加合同编号展示、合同结算调整、票款强绑定、审批、自动应收／应付、期限／催收或内部成本。附件继续由 Evidence Service 拥有；合同继续由 Contract Ledger 拥有；实际资金继续由 Money Flow Ledger 拥有。
