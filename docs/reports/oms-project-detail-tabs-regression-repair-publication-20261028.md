# OMS 项目详情标签回退故障修复与发布记录

日期：2026-10-28
范围：BF-285
状态：故障原因确认、修复发布与公网真实浏览器验收通过

## 问题与根因

用户只要求重组“项目详情”，但公网 v1.55 同时丢失了当前侧栏入口，并把项目列表回退成旧的四项金额布局。根因不是业务数据或 Owner 异常，而是发布时错误地从 BizFoundry 中已停滞的同名 Workbench 目录构建；该旧源码缺少 OMSBoundry v1.52 已有的完整侧栏、项目统计摘要、六列列表及 BF-281～BF-284 的近期修复。

## 修复结果

- 发布源恢复为本仓库 `frontend/oms-workbench`，并用公网发布前 v1.52 的 CSS／JS 摘要核对当前源码基线。
- 变更只发生在项目详情覆盖层：新增“概览／往来单位／合同／收付款”四个标签，并支持左右方向键、Home、End 切换。
- 概览组合基本信息、收付摘要和最近记录；往来单位显示甲方与施工方；合同显示主合同、下游合同和金额变更；收付款保留开票、回款、收票、支付逐笔明细和施工方拆分。
- 产品侧栏、公司内部管理、开放平台、账号与租户、产品反馈均保留；项目列表恢复统计摘要、六列结构、排序、项目开启日期、应收／应付状态和最右详情动作。
- BF-281 的六个应收／应付记录子入口项目标签、来源返回文案、原列表状态和焦点恢复均保留。
