# OMS 账号目录排版本地验证（2026-10-30）

## 目标

把“账号与租户”从等权概览和流程说明组成的展示页，收敛为可快速识别账号、成员关联、权限与状态的管理工作区。

## 本地候选

- 四块概览改为一条无卡片组织上下文，仅显示组织名称、账号数、管理员数和可用账号数。
- 账号开通三步说明移入新增账号对话框，并保留默认折叠的帮助入口。
- 姓名与登录标识合并为“用户／登录账号”，当前登录账号直接标记。
- IAM Subject 与 People Person 只按稳定 `iam_subject_id` 做内存连接，行内显示成员关联；无关联明确显示“不影响登录”。
- 增加姓名／登录标识／成员搜索，以及级别、状态和关联状态筛选；筛选不持久化、不写 Owner。
- 重置密码、管理员调整和启停继续调用既有命令，但收进每行操作菜单。
- 页面内容限制在 1440px，宽屏保持集中阅读；窄屏筛选换行，表格保留安全横向滚动。
